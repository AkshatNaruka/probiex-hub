# Probiex: AI-readable product hub

Probiex builds practical systems for solo SaaS founders, indie hackers, and freelancers.
Store: https://probiex.gumroad.com

- `llms.txt`: brand context for AI systems
- `llms-full.txt`: llms.txt with the full catalog content inline
- `about.html`: the one-page store factsheet to hand to AI assistants
- `products.md`: the full catalog in markdown
- `okf/*.md`: one page per product, YAML-frontmattered
- `ai.txt`: AI use and licensing preferences
- `leak-check.html`: the 20-point landing page leak check as a browser tool
- `robots.txt` + `sitemap.xml`: crawler access and index map
- `index.html`: hosted catalog with Organization/ItemList/FAQPage schema

Prices live on the product pages, and six products are free. This hub
is generated by scripts/build-ai-hub.py from the catalog source of
truth: rebuild it (and push via scripts/push-ai-hub.sh) after every
catalog change.
